# T02: Low-stock report

The warehouse wants to see what is running out before it runs out.

## Acceptance criteria

1. `inventory.lowStock(store, threshold)` returns the products whose stock is at or below
   `threshold`, as `{ sku, name, stock }`.
2. The list is ordered by stock, lowest first; products with equal stock are in sku order.
3. `threshold` defaults to 5. A threshold that is not a whole number of zero or more is
   refused with code `BAD_THRESHOLD`.
4. `GET /inventory/low?threshold=N` returns that list as `{ items: [...] }` for a signed-in
   user, 401 without a session, and 400 for a bad threshold.

## Out of scope

- Reorder suggestions, notifications.
