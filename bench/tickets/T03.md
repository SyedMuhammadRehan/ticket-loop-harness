# T03: Order totals are a cent short

Finance found orders where the discount is a cent too small. Example: a 9.99 tape measure
with SPRING15 gets 1.49 off; 15% of 9.99 is 1.4985, which should be 1.50.

## Acceptance criteria

1. Every percentage amount in an order is rounded half up to the nearest cent.
2. The example above takes 1.50 off.
3. Amounts stay whole cents everywhere; nothing is stored or compared as a fraction.
