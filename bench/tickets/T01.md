# T01: Product search skips the first results

Reported by support: on the product list, the first page is missing items. With a page size of
3, page 1 shows the 4th to 6th products, and the last page comes back empty.

## Acceptance criteria

1. Page 1 of a search returns the first `pageSize` matches in sku order.
2. Each later page continues where the previous one stopped, with no gap and no repeat.
3. A page past the end returns no items, and `total` still reports the number of matches.
