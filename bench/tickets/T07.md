# T07: Cancelling an order twice inflates stock

A customer double-clicked "cancel" and the warehouse now shows two saws it does not have.
Each cancel gives the stock back again.

## Acceptance criteria

1. Cancelling a placed order sets it to `cancelled` and returns its stock, once.
2. Cancelling an order that is already cancelled is refused with code `ALREADY_CANCELLED`,
   and stock does not change.
3. Cancelling an order that has shipped is refused with code `ALREADY_SHIPPED`, and stock
   does not change.
4. Over HTTP both refusals are a 409.
